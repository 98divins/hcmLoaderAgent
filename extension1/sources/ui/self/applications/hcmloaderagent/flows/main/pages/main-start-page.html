Chargement en masse HCM build 20

1. Que voulez-vous charger ?

Cliquez sur un objet. Il determine les fichiers attendus et les operations possibles.

2. Que voulez-vous faire ?

Un dossier porte une seule operation. Cliquer ouvre le dossier.
Dossier

Deposez vos fichiers CSV, un par objet, ensemble ou l'un apres l'autre. La page reconnait l'objet de chaque fichier a ses colonnes.
Choisissez comment charger
La page charge pour vous, sous votre identite. Ou vous recuperez le fichier et le deposez vous-meme dans HCM Data Loader.
